# Nom de l'application

Projet conçu en équipe avec :Khushi Thapa, Dalia chenaoui, Hadassa Alliance

## Le problème

- Problème :
  -difficile de trouver le fichier
  -difficile/problématique de partager le fichier
  
- Persona : les élèves qui veulent reserver des matroaux. et les  ttti's qui regardent les demandes pour les completer.
    - En tant qu'eleve, je veux que ce sois plus facile a partager le fichier afin de ne pas perdre tros de temps.
    -En tant qu'eleve, je veux que ce sois plus facile a trouver le fichier d'exel afin de ne pas perdre tros de temps.
## La solution

- Proposition de valeur : car c'est plus effective et moins compliquée. 
- Fonctionnalités du MVP :
  - les matériaux facile a trouver et classé par cour
  - les informations(conte qui est/peut etre sauvgarder)
  - date(48 heure de plus en base)
  - notification 30 minute en avance pour prendre les matériaux
  - notification/pop up pour les ccti's quand on reserve(quand ils ouvrent ils voyent le nom, DA et les matéraux reservées)
